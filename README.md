# Mercúrio

Mercúrio é uma aplicação independente criada para resolver um problema muito comum no ambiente universitário: **o esquecimento de prazos e datas de entrega de atividades acadêmicas.**

O projeto nasceu de uma dificuldade pessoal que enfrento durante minha vida universitária. Prazos longos, que acabam sendo esquecidos com o passar do tempo, inúmeras atividades para entregar, responsabilidades pessoais e a falta de tempo para se organizar. Tudo isso contribui para que, em algum momento, aquela atividade importante do semestre acabe passando despercebida.

Foi pensando nisso que surgiu o **Mercúrio**, uma tentativa de solucionar, mesmo que parcialmente, esse problema. A proposta é simples: enviar lembretes periódicos pelo WhatsApp, avisando sobre atividades que estão próximas de suas datas de entrega, ajudando o estudante a se manter informado sobre seus compromissos acadêmicos.

Inicialmente, a aplicação foi pensada para funcionar de maneira integrada ao **Google Classroom**, consultando as atividades e seus respectivos prazos para gerar os lembretes automaticamente.

O objetivo do Mercúrio não é substituir a organização pessoal de cada estudante, mas oferecer uma ferramenta que facilite esse processo e diminua as chances de uma entrega importante ser esquecida.
